TECHNOVA

TECHNOVA is a practice web development project created to improve my frontend and backend development skills. The website features a modern AI-themed design and integrates a chatbot powered by the Groq API.

Project Overview

This project was built to gain hands-on experience with:

- Responsive web design
- Frontend development
- Backend integration
- AI chatbot implementation
- Local server configuration
- Database connectivity

Features

- Responsive AI-themed website
- Animated global background video
- Interactive navigation
- About, Services, Products, Team and Contact sections
- AI Chatbot using the Groq API
- Contact form
- Mobile-friendly design

Technologies Used

Frontend
- HTML5
- CSS3
- JavaScript

Backend
- PHP
- Python (Flask)

Database
- MySQL

Local Server
- XAMPP (Apache & MySQL)

APIs
- Groq API

Purpose

This project was developed as a learning exercise to explore the integration of frontend technologies with backend services, databases, and AI APIs.

Future Improvements

- User authentication
- Admin dashboard
- Live database integration
- Deployment to a cloud platform
- Enhanced chatbot capabilities
