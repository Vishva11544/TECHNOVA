TECHNOVA

TECHNOVA is a practice web development project created to improve my frontend and backend development skills. The website features a modern AI-themed design and integrates a chatbot powered by the Groq API.

Project Overview

This project was built to gain hands-on experience with:

- Responsive web design
- Frontend development
- Backend integration
- AI chatbot implementation
- Local server configuration
- Database connectivity

Features

- Responsive AI-themed website
- Animated global background video
- Interactive navigation
- About, Services, Products, Team and Contact sections
- AI Chatbot using the Groq API
- Contact form
- Mobile-friendly design

Backend

Database

Local Server
- XAMPP (Apache & MySQL)

APIs
- Groq API

How to Run

1. Install XAMPP and start Apache and MySQL.
2. Place the project folder inside the `htdocs` directory.
3. Create a `.env` file and add your Groq API key:

```env
GROQ_API_KEY=YOUR_API_KEY
```

4. Create the required MySQL database in phpMyAdmin.
5. Run the Python backend:

```bash
python 04_app.py
```

6. Open the project in your browser:

```
http://localhost/TECHNOVA/
```
